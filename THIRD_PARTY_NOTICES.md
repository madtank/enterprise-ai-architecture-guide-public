Generated MkDocs output is intentionally excluded from this source
distribution. A generated site can copy theme, icon, search, JavaScript, font,
source-map, and other assets governed by separate terms. Before distributing a
site, inventory the exact build output, include all required licenses and
attributions, preserve embedded notices, review external requests and source
maps, and repeat the privacy and clean-artifact checks.

is intentionally vendored in this source distribution. Report a suspected
omission through [SUPPORT.md](SUPPORT.md) without posting confidential or
personal evidence publicly.
